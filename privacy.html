Privacy Policy

Last updated: 12 October 2026

The short version: Brainrot collects no personal data. Its settings and counters stay in your browser, nothing is sent to us or anyone else, and there is no account.

This policy covers the Brainrot browser extension for Chrome and Firefox ("the extension"), this website at botjaeger.github.io/brainrot ("the website"), and the Google Cloud project used to publish the extension ("the Google app").

What the extension collects

Nothing. The extension has no servers, no analytics, no tracking and no advertising. It never reads your messages, posts, comments, contacts, account details or browsing history, and it never sends any data off your device.

What the extension stores on your device

To work, the extension keeps a few values in your browser's own extension storage (storage.local). They never leave your device:

  • whether Brainrot is switched on, and your light or dark theme;
  • how many videos it moved past on each supported site, all-time and for today, plus today's date so the daily count can reset at midnight;
  • the last version whose "What's new" page you opened;
  • a debug logging switch, off by default.

"Reset stats" in the popup clears the counts. Removing the extension deletes all of it.

Why the extension needs its permissions

  • Access to www.youtube.com, www.tiktok.com, www.instagram.com and www.facebook.com: to run on those sites. It acts only on YouTube Shorts, TikTok feeds, and Instagram and Facebook Reels: it watches the playing video for its end, then clicks the site's own "next" button or scrolls the feed. On feed pages it also keeps the video playing when you switch tabs. It does nothing on any other page.
  • storage: to keep the settings and counts listed above.
  • tabs: to show in the popup whether the current tab is a supported feed, to reload open feed tabs after an install or update so the new version takes effect, and to open the "What's new" page. The tab's address is read on your device and never stored or sent.
  • scripting: to register the script that keeps videos playing in background tabs.

The website

The website has no cookies, no sign-up and no analytics. Its fonts are served from the website itself. It is hosted by GitHub Pages, and GitHub may log technical data such as your IP address for security purposes; see the GitHub Privacy Statement. If you reach a copy of the website hosted on Vercel, that copy counts anonymous page views with Vercel Web Analytics, which uses no cookies.

The install buttons link to the Chrome Web Store and Firefox Add-ons, which have their own privacy policies.

Google API access

The Google app exists only so the developer's release process can upload new versions of the extension to the Chrome Web Store, using the Chrome Web Store API. It is used by the developer alone. Users of Brainrot never sign in with Google, and the Google app requests no access to any user's Google account or data.

Brainrot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Children

Brainrot is not directed at children under 13 and collects no information from anyone, including children.

Changes to this policy

If this policy changes, the new version is posted on this page with a new "Last updated" date. Because Brainrot collects no data, a change cannot affect data already collected about you.
